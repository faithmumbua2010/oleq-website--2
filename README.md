# OLEQ Website

A modern and responsive business website developed for **OLEQ**, a software solutions company providing tailored digital solutions for businesses.

The website showcases OLEQ's services, client testimonials, technology-related articles, and contact information in a clean and user-friendly interface.

## Live Demo

**[View the live website](https://oleq-website-2.vercel.app/)**

## About the Project

The OLEQ website was designed to provide businesses with information about the company's software development and technology services while creating a professional digital presence.

The website focuses on presenting OLEQ's services clearly and making it easy for potential clients to learn more about the company and get in touch.

## Features

* Responsive and adaptive design
* Modern navigation bar
* Hero section with call-to-action buttons
* Services section
* Client testimonials section
* Blog/news section
* Contact section with a contact form
* Company information and footer navigation
* Responsive layouts for different screen sizes
* Smooth and user-friendly interface

## Services Showcased

The website highlights the following services:

* **Custom Software Development**
* **Web Application Development**
* **Mobile App Development**
* **Database Solutions**
* **Business Intelligence**
* **System Integration**

##  Technologies Used

* **HTML5** – Website structure and semantic markup
* **CSS3** – Styling, layouts, responsiveness, and animations
* **JavaScript** – Interactivity and dynamic functionality
* **Vercel** – Deployment and hosting

##  Responsive Design

The website is designed to adapt to different screen sizes, including:

* Mobile devices
* Tablets
* Laptops
* Desktop monitors
* Larger desktop screens

Responsive CSS techniques and media queries are used to maintain a consistent experience across different devices.
